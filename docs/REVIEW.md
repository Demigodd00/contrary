# Reviewer path (StudioNet)

1. Open the [public Contrary app](https://contrary-inky.vercel.app/?claim=CT-V2-EMPTY-001) without signing in. The claim detail should show the frozen `examples/validator.py` source, the full-commit link, the counterexample `name = ''`, and two separate validator assessments with exact source quotes. The source was captured from commit `e88ec082d060a441f1b01599ad65f5f2ec2f8cb2`; it does not depend on the current branch head.
2. Open [`/deployment.json`](https://contrary-inky.vercel.app/deployment.json). It should identify StudioNet chain 61999, version `contrary.v0.2.0`, and contract `0xce7F96AFFCC1edA8dCAa57D5fB14fD658C96Ca64`. Compare the on-chain source hash and config with [`deployments/contrary_studionet.json`](../deployments/contrary_studionet.json). The app refuses wallet writes if the deployed source differs.
3. Inspect the public transactions and final state in [`deployments/acceptance_studionet.json`](../deployments/acceptance_studionet.json). A submitted or accepted hash is not enough: the record distinguishes FINALIZED/SUCCESS execution, the contract's claimable credit, and the separate outbound withdrawal transfer's `value_credited` result.
4. To reproduce with fresh test wallets, connect a StudioNet wallet in the app and post a different `CT-...` claim against a public self-contained source file at a full 40-character commit. The contract requires 0.01–1 simulated GEN and a challenge period from 1 to 14 days. From a different wallet, submit a concrete contrary input and stake exactly 10% of the reward. Anyone can request validator review. Either party can rebut once within ten minutes, and anyone can finalize after the window. An account with claimable credit then withdraws separately. A new claim is required; the pinned acceptance claim is already used.

This app adjudicates static claims inferable from one complete source file. Validators do not execute arbitrary code or verify imported files and runtime logs. Rejected, inconclusive, unreviewed and expiry cases are covered by direct tests, not presented as live multi-wallet acceptance. The write path in a production browser wallet has not been independently exercised by the maintainer. StudioNet GEN is simulated and has no monetary value.
