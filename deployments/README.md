# Deployment records

`contrary_studionet.json` identifies the canonical v0.2.0 contract and its independently checked on-chain source. `acceptance_studionet.json` records live v0.2.0 claim, review, settlement and withdrawal transactions once finalized. Earlier releases remain in `history/`; they are not evidence that the current contract has settled.

These records contain public addresses and hashes only. Disposable operator keys stay in ignored `.local/` and are never submission evidence.
